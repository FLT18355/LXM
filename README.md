# 蓝汐音乐 (lxm-tui) · r-1.0

OpenTUI 版本地音乐播放器，基于 **mpv JSON IPC**。由 curses 的 `lxm.py` 移植而来。
界面已整体重做：宽屏分栏、窄屏堆叠，正在播放 / 歌词 / 队列预览放在侧栏，列表留给内容。

## 界面

宽终端（≥ 100 列）：

```
 蓝汐音乐  ♪ 播放列表                      ↻ 列表循环 · 顺序 · 72%
 ┌ 正在播放 ─────────────────┐  ♪ 播放列表  ♥ 收藏  ❏ 歌单  ⚙ 设置  ≡ 队列
 │ ▶ 播放  夜空中最亮的星     │  ─────────────────────────────────────────
 │ 洛天依 · MP3 · 3/34 · ♪7  │  ┌ 播放列表 ──────────────────────────────┐
 │ ████████▏──────── 02:41/04:12 │  1 稻香                    ♥ ♪3 mp3 03:00 │
 │ ▂▅▃▇▆▂▄▅▃▂▄▆▇▅▂▃▆▄▂▅▃▆▇▂▄▅ │ ▶2 反乌托邦…                  ♪7 mp3 03:30 │
 └───────────────────────────┘  │  3 夜空中最亮的星          ♥ ♪2 m4a 04:00 │
 ┌ 歌词 ─────────────────────┐  └────────────────────────────────────────┘
 │    风穿过城市              │
 │ ♪ 我在人海里听见你         │
 │    反乌托邦的清晨          │
 └───────────────────────────┘
 ┌ 接下来 ───────────────────┐
 │ 1 南征北战-着魔   04:30   │
 └───────────────────────────┘
 空格 播放/暂停 · n/p 切歌 · w 插队 · f 收藏 · / 搜索 · h 帮助 · q 退出
```

- **宽屏分栏**：左栏固定为「正在播放 + 歌词 + 接下来」，右栏为标签栏和列表/设置/队列。
- **窄屏（< 100 列）自动堆叠**：正在播放卡片置顶，隐藏歌词与队列预览；歌词可用 `L` 全屏查看。
- **正在播放卡片**：状态、歌名、艺术家/格式/曲序/播放次数、渐变进度条（8 分块）、程序化频谱；
  进度条支持鼠标点击/拖动定位。
- **列表行**：`播放标记 + 序号 + 歌名 + ♥ + ♪次数 + 格式 + 时长`；选中行整行高亮 + 左侧指示条，
  正在播放行使用呼吸高亮；超长歌名仅在选中行内滚动（跑马灯），换行从 0 重新开始。
- **上下文状态栏**：快捷键提示跟着视图变化（列表 / 收藏 / 歌单 / 队列 / 设置各一套），
  不再永远显示一整条长清单；右侧固定显示总播放次数、曲序与音量。
- **空状态**：收藏为空、歌单为空、队列为空、搜索无结果、音乐库为空都有对应操作提示。
- **设置页**：对齐的「标签 + 当前值 + ◂ ▸」，`←/→` 调整、`Enter` 执行；
  主题切换即时生效并重建配色。
- **弹层**：帮助（双栏）、歌曲信息、排序、统计、目录管理、歌单/目录输入、危险操作确认、
  全屏歌词；统一为居中圆角卡片 + 纯色遮罩，层级固定（确认 > 输入 > 帮助 > 其它）。
- **通知**：右下角滑入淡出（最多 3 条），同时底部状态栏保留最近一条消息。
- **鼠标**：点击标签、点击列表行、滚轮滚动列表、拖动进度条。
- **动效克制**：logo 渐变、频谱、进度条高光、播放行呼吸、标签下划线滑动；
  仅重画装饰节点，列表内容由单一渲染路径写入，避免闪烁。

## 特性

- 播放 / 暂停 / 上一首 / 下一首（mpv 驱动，支持全格式）
- 三种循环模式：不循环 / 列表循环 / 单曲循环；随机播放
- LRC 歌词实时滚动；歌词区常显（无歌词或关闭时给出说明），`L` 全屏 KTV 歌词
- 中文搜索（原生 Unicode 输入框）；在收藏视图内搜索只搜收藏
- 收藏：`f` 收藏/取消当前曲；收藏视图（`2`）内增删会立即刷新列表
- 歌单：创建 / 重命名 / 删除（删除需确认），进入详情、加歌、移除，独立持久化为 `playlists.toml`
- 播放队列（`5`）：查看播放顺序，`Enter` 播放 · `x` 移除 · `J/K` 移动 · `c` 清空待播；
  清空只保留当前曲，不再偷偷把整库塞回队列
- 队列操作：`w` 下一首播放（插队）· `e` 加入队列末尾
- 多音乐目录：`music_directories` 任意多个目录合并去重扫描；设置 → 音乐目录进入管理弹层
  （`a` 添加 · `d` 移除 · `Enter` 设为主目录）。旧的单目录 `music_directory` 继续兼容并作为主目录回写
- 列表排序（`o`）：默认路径 / 歌名 / 时长 / 播放次数 / 格式 / 所在目录，升降序，持久化
- 音乐库统计（`S`）：曲目数 · 已知总时长 · 总播放次数 · 收藏/歌单/目录数 · 格式分布 ·
  播放次数 Top · 最近播放
- 设置（`4`）：主题（Catppuccin 四口味）· 音量 · 倍速 · 歌词延迟（-5~5s，0.25 步进）·
  睡眠定时 · 音乐目录 · 排序 · 缓存 · 版本；改动即时生效并自动保存
- 断点续播：退出记住歌曲与位置，重开自动续播；恢复播放**不计入**播放次数
- 切歌淡入淡出；静音切换（`M` / `0`）；睡眠定时到点渐弱 7 秒后暂停
- 歌曲信息弹层（`i`）；歌曲文件编辑：`R` 重命名（含同名 `.lrc`）、`D` 删除（确认后删磁盘文件），
  并同步收藏、歌单、播放次数、时长缓存、扫描缓存与断点续播
- 缓存目录 `~/.cache/lxmusic/`：断点续播状态 + 扫描缓存 + 播放次数（含最近播放时间）+ 时长缓存
- 秒开界面：先渲染 UI，mpv 后台异步启动；未就绪时播放操作会提示而不是静默失败
- 终端尺寸自适应：宽度跨过 100 列时自动在分栏/堆叠布局间切换

## 本次重构修复的问题

- 队列视图下 `f / R / D / w / e` 误用 playlist 下标，现在统一走 `queue[sel]`。
- 收藏视图内取消收藏后列表不刷新（残留幽灵行）；收藏为空时也能进入视图并显示空状态。
- 在收藏/搜索结果里切换随机会把队列重置成整库，列表突然变成全部歌曲；现在保留过滤集合。
- `c` 清空队列时若当前曲不在队列，会重建整库并重置当前曲；现在只保留当前曲或清空。
- 断点续播先 `loadfile` 再设置 `pendingSeek`，首帧可能已过 `time-pos>0.2` 导致位置丢失；现已调整顺序。
- 启动恢复上次歌曲会额外累加一次播放次数；恢复路径改为 `playIndex(idx, { count: false })`。
- `speed` 配置读入后从未应用；现在启动恢复，并在 mpv 连接后下发。
- 添加音乐目录的 `~` 不会展开；现在统一展开为 home 目录。
- 歌词区高度超过 20 行时停止刷新；现在按面板高度重建歌词行。
- 删除歌单没有确认，误按 `d` 直接丢失；现在走确认弹层。
- 主题切换重建节点后，旧通知节点引用失效；重建时清空节点引用。
- 搜索结果退出时把队列重置成整库、丢失随机/收藏过滤；现在保存并恢复搜索前状态。

## 运行

```bash
# 需要 bun (>= 1.3.0) 和 mpv
bun install        # 首次
bun index.ts                       # 启动 (使用配置中的音乐目录)
bun index.ts /path/to/music        # 指定目录启动
bun index.ts -v / --version        # 显示版本
bun index.ts config                # 查看音乐目录
bun index.ts config --music-directory /path/to/music   # 追加/置顶音乐目录
bun index.ts cache                 # 查看缓存目录
bun index.ts cache --clear         # 清空缓存
```

配置保存在 `~/.config/lxmusic/config.toml`（与 Python 版兼容，可混用）；
缓存与运行时状态在 `~/.cache/lxmusic/`（可随时清空，不影响配置）。

## 编译为二进制

```bash
bun run build           # → dist/lxm-tui (单文件, 已内嵌 OpenTUI 原生 .so)
./dist/lxm-tui          # 直接运行, 无需 bun / 无需 node_modules

bun run build:portable  # → dist-js/ (可分发目录, 运行时外置)
./dist-js/lxm.sh        # 薄壳启动器; 也可 ./dist-js/lxm-tui .
```

两种产物都仍依赖系统 `mpv`。目标平台由 `--target` 指定（默认 `bun-linux-arm64`）。

**UPX 注意**：单文件 `dist/lxm-tui` **不能**用 UPX 压（会破坏尾部模块图，启动报
`SyntaxError: Invalid character: '\0'`）。

## 结构

```
index.ts          入口: 参数 / 多目录扫描 / mpv 启动 / renderer / 主循环 / 清理
src/config.ts     配置读写 (TOML, 兼容 Python 版) + 多音乐目录解析
src/cache.ts      缓存目录 ~/.cache/lxmusic/ (断点续播 / 扫描缓存 / 播放次数+最近时间 / 时长)
src/scanner.ts    音乐目录递归扫描 (单目录 + 多目录合并去重, 带缓存)
src/version.ts    版本号唯一来源 (改版本只动这处; package.json 手动同步)
src/duration.ts   后台批量探测歌曲时长 (列表右侧显示)
src/lrc.ts        LRC 歌词解析
src/mpv.ts        mpv JSON IPC 客户端 (Bun unix socket, 事件驱动)
src/player.ts     播放器状态与逻辑 (队列操作 / 排序 / 睡眠定时 / 收藏 / 歌单)
src/playlists.ts  歌单持久化 (TOML 子表数组)
src/stats.ts      音乐库统计 (统计面板数据来源)
src/theme.ts      Catppuccin 四口味主题 (Latte / Frappé / Macchiato / Mocha)
src/ui.ts         界面控制器: 布局 / 视图 / 按键 / 弹层 / 主循环
src/ui/gfx.ts     文本宽度 (CJK 计 2 列) / 截断 / 跑马灯 / 进度条 / 渐变
src/ui/widgets.ts 节点构建器: 顶栏 / 播放卡片 / 歌词 / 标签 / 列表 / 状态栏 / 通用弹层
```
